# Article Page Overrides

## Layout

- 1160px outer container.
- Article header uses the warm background without a containing card.
- Reading body uses a white 3px outlined panel with an 8px navy offset shadow.
- Prose remains 65-75 characters wide.
- Desktop table of contents is a sticky soft-blue card; mobile uses a bordered disclosure above the prose.
- Comments sit in their own white outlined panel after the article.

## Typography

- Article title uses Fredoka for Latin and rounded system sans for Chinese, 42-60px desktop and 34-42px mobile.
- Body text uses Nunito plus Chinese system sans, never Fredoka.
- Code uses a native monospace stack and a dark navy surface.

## Color

- Green highlights categories and active table-of-contents state.
- Coral is reserved for one supporting metadata block.
- Blue is reserved for navigation and the table of contents.

## Accessibility

- Active table-of-contents links use an underline plus color.
- Code blocks scroll horizontally without widening the page.
- Giscus loading and error regions reserve space and use `aria-live`.
