# 文章页紧凑排版设计规格

日期：2026-08-08

## 目标

在保留当前卡片视觉、文章宽度和技术博客可读性的前提下，缩短文章目录、正文标题和内容块之间过长的纵向距离，让一屏能够承载更多有效内容。桌面端目录应更像紧凑的文章索引；移动端仍需保留足够大的触控区域。

## 设计范围

本次只调整文章详情页中的正文卡片和目录排版，不修改首页、文章数据、Markdown 内容、评论区、上下篇导航、配色或页面结构。

## 排版规则

### 正文卡片

- `.reading-card` 使用 `padding: clamp(22px, 4vw, 44px)`，把桌面端最大内边距从 52px 缩至 44px。
- 移动端继续使用现有的 `22px 18px`，避免窄屏正文被进一步挤压。
- `.prose` 保持 `72ch` 最大行宽；桌面字号继续为 `1.02rem`，移动端继续为 `1rem`。
- `.prose` 行高从 `1.82` 调整为 `1.72`，提升信息密度，同时保留中文和代码术语混排所需的呼吸感。

### 标题节奏

- H2：字号保持 `1.75rem`，外边距调整为 `1.45em 0 .5em`，在默认桌面字号下约为上 41px、下 14px。
- H3：字号保持 `1.35rem`，外边距调整为 `1.3em 0 .45em`，约为上 28px、下 10px。
- H4：补充明确样式，字号 `1.08rem`、行高 `1.35`、外边距 `1.15em 0 .4em`，避免 Markdown 四级标题沿用浏览器默认的大间距。
- H2、H3、H4 继续使用当前标题字体、字距和 `scroll-margin-top: 28px`，确保目录锚点跳转后标题不会贴住视口顶部。

### 正文内容节奏

- 段落使用 `margin: .8em 0`。
- 一级无序列表和有序列表使用 `margin: .8em 0`、`padding-left: 1.5em`。
- 相邻列表项之间使用 `.25em` 的顶部间距；嵌套列表使用 `.45em 0`，减少长列表中的空洞感。
- 图片、代码块、表格和引用块的上下外边距统一由 `1.8rem` 缩至 `1.4rem`。
- 代码块内部的行高、内边距和横向滚动规则保持不变，避免降低代码可读性。

## 目录规则

### 桌面端目录

- `.toc-desktop` 内边距从 20px 调整为 16px。
- 目录列表顶部外边距从 12px 调整为 8px。
- 每个列表项的垂直外边距从 9px 调整为 2px。
- 目录链接最小高度从 44px 调整为 30px，行高使用 `1.3`；预期相邻目录项的垂直步进不超过 34px。
- 嵌套目录缩进从 12px 调整为 10px。
- 保留 sticky 定位、当前章节高亮、颜色和下划线反馈。

### 移动端目录

- `.toc-mobile a` 单独恢复 `min-height: 44px`，满足触控尺寸要求。
- 移动目录仍使用折叠面板；摘要按钮、面板样式和展开行为不变。

## 响应式与可访问性

- 桌面端和窄屏均不得出现页面级横向滚动。
- 移动端目录链接和摘要按钮的可点击高度不得小于 44px。
- 键盘焦点、当前章节状态和减少动态效果的现有行为保持不变。
- 此次只改变间距与排版密度，不删减文章结构或导航信息。

## 验收标准

1. 1273px 宽视口下，桌面目录相邻项目的垂直步进不超过 34px，15 项目录不再占据约 800px 高度。
2. 1273px 宽视口下，H2 上外边距约 41px、下外边距约 14px；H3 上外边距约 28px、下外边距约 10px。
3. 375px 宽视口下，移动目录链接与摘要按钮的最小高度均不低于 44px。
4. 正文行高计算值接近字号的 1.72 倍；段落、列表、图片、代码块、表格和引用块形成连续而不拥挤的阅读节奏。
5. 页面在桌面和移动视口均无水平溢出，目录锚点、评论区和上下篇导航功能不受影响。
6. 样式测试覆盖正文行高、标题外边距、内容块间距、桌面目录密度以及移动目录触控高度。

## 实现边界

- 主要修改 `src/styles/global.css`。
- 在 `src/lib/styles.test.ts` 中补充或更新对应的 CSS 回归断言。
- 不新增依赖，不修改 Astro 组件结构，不改动文章 Markdown 文件。
